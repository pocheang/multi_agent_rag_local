### 1. ✅ Session管理 + CSRF Token绑定

**文件**: `app/services/auth/enhanced_session.py`

**实现功能**:
- ✅ Redis-backed session存储（支持分布式部署）
- ✅ CSRF token与session绑定
- ✅ 常量时间比较防止时序攻击 (`secrets.compare_digest`)
- ✅ 自动session过期和清理
- ✅ 文件存储fallback（Redis不可用时）

**核心代码**:
```python
class EnhancedSessionManager:
    def create_session(self, user_id, username, role) -> tuple[str, str]:
        """创建session并生成CSRF token"""
        session_id = secrets.token_urlsafe(32)
        csrf_token = secrets.token_hex(32)
        
        session_data = {
            "user_id": user_id,
            "username": username,
            "role": role,
            "csrf_token": csrf_token,  # 绑定到session
            "created_at": datetime.utcnow().isoformat(),
        }
        
        self.store.set(session_id, session_data, ttl_seconds)
        return session_id, csrf_token
    
    def validate_csrf_token(self, session_id, csrf_token) -> bool:
        """验证CSRF token（常量时间比较）"""
        session = self.get_session(session_id)
        if not session:
            return False
        
        stored_token = session.get("csrf_token")
        if not stored_token:
            return False
        
        # 常量时间比较防止时序攻击
        return secrets.compare_digest(stored_token, csrf_token)
```

**存储后端**:
- **Redis**: 分布式部署，自动TTL
- **文件**: 单实例fallback

### 2. ✅ Redis速率限制

**文件**: `app/services/auth/redis_rate_limit.py`

**实现功能**:
- ✅ Redis滑动窗口算法
- ✅ 分布式速率限制（多实例共享状态）
- ✅ 自动过期清理
- ✅ 内存fallback（Redis不可用时）

**核心代码**:
```python
class RedisRateLimiter:
    def _check_redis(self, key, max_requests, window_seconds):
        """Redis滑动窗口速率限制"""
        current_time = time.time()
        window_start = current_time - window_seconds
        
        pipe = self.redis_client.pipeline()
        
        # 删除过期条目
        pipe.zremrangebyscore(key, 0, window_start)
        
        # 计数当前窗口内的请求
        pipe.zcard(key)
        
        # 添加当前请求
        pipe.zadd(key, {str(current_time): current_time})
        
        # 设置过期时间
        pipe.expire(key, window_seconds + 1)
        
        results = pipe.execute()
        current_count = results[1]
        
        if current_count >= max_requests:
            # 计算retry_after
            oldest = self.redis_client.zrange(key, 0, 0, withscores=True)
            if oldest:
                oldest_time = oldest[0][1]
                retry_after = int(window_seconds - (current_time - oldest_time)) + 1
                return False, retry_after
            return False, window_seconds
        
        return True, None
```

**优势**:
- ✅ 支持水平扩展（多个后端实例共享限流状态）
- ✅ 精确的滑动窗口算法
- ✅ 自动清理过期数据

**实现**:

```python
def get_session_id_from_cookie(request: Request) -> Optional[str]:
    """从HttpOnly cookie提取session ID"""
    return request.cookies.get("session_id")

class CSRFProtectionMiddleware:
    async def dispatch(self, request, call_next):
        # 从HttpOnly cookie读取session
        session_id = get_session_id_from_cookie(request)
        
        # 验证CSRF token与session匹配
        if not session_manager.validate_csrf_token(session_id, csrf_token):
            return JSONResponse(status_code=403, ...)
```

**如何使用** (在auth endpoint):
```python
from fastapi import Response

@router.post("/auth/login")
async def login(response: Response):
    # 创建session
    session_id, csrf_token = session_manager.create_session(...)
    
    # 设置HttpOnly cookie
    response.set_cookie(
        key="session_id",
        value=session_id,
        httponly=True,      # JavaScript无法访问
        secure=True,        # 仅HTTPS传输
        samesite="strict",  # 防CSRF
        max_age=86400       # 24小时
    )
    
    # 返回CSRF token给前端（存储在sessionStorage）
    return {"csrf_token": csrf_token, "user": ...}
```

**安全优势**:
- ✅ Session ID对JavaScript不可见（防XSS）
- ✅ Secure标志强制HTTPS
- ✅ SameSite防止CSRF
- ✅ CSRF token仍通过header验证（双重保护）

4. Vite配置需要支持nonce注入

### 从localStorage Token到HttpOnly Cookie

**当前状态** (前端):
```typescript
// Token存储在localStorage
localStorage.setItem("auth_token", token);
```

**迁移后** (前端):
```typescript
// Token自动存储在HttpOnly cookie中（后端设置）
// 前端只需存储CSRF token
sessionStorage.setItem("csrf_token", csrf_token);
```

**后端更新** (auth endpoint):
```python
from fastapi import Response
from app.services.auth.enhanced_session import get_session_manager

@router.post("/auth/login")
async def login(credentials: LoginRequest, response: Response):
    # 验证用户
    user = authenticate(credentials.username, credentials.password)
    
    # 创建session（包含CSRF token）
    session_manager = get_session_manager(
        redis_url=settings.redis_url,
        session_ttl=settings.session_ttl_seconds
    )
    session_id, csrf_token = session_manager.create_session(
        user_id=user.id,
        username=user.username,
        role=user.role
    )
    
    # 设置HttpOnly cookie
    response.set_cookie(
        key="session_id",
        value=session_id,
        httponly=True,
        secure=settings.use_secure_cookies,  # True in production
        samesite="strict",
        max_age=settings.session_ttl_seconds
    )
    
    # 返回CSRF token和用户信息
    return {
        "csrf_token": csrf_token,  # 前端存储在sessionStorage
        "user": user.dict(),
        "token_type": "bearer"
    }
```

**前端更新** (auth.ts):
```typescript
async login(username: string, password: string) {
  const response = await request<LoginResponse>("/auth/login", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ username, password }),
    credentials: "include"  // 重要: 发送和接收cookie
  });
  
  // Session ID在HttpOnly cookie中（JavaScript无法访问）
  // 只需存储CSRF token
  if (response.csrf_token) {
    sessionStorage.setItem("csrf_token", response.csrf_token);
  }
  
  return response;
}
```
