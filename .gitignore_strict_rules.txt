# ============================================
# GitHub 发布严格规则
# ============================================

## 允许发布的内容

### 1. 源代码
- app/**/*.py (应用代码)
- frontend/src/**/* (前端代码)
- tests/**/*.py (测试代码)
- scripts/**/*.py (工具脚本)
- deploy/**/*.py, deploy/**/*.sh (部署脚本)

### 2. 配置文件（仅示例/模板）
- .env.example (环境变量模板)
- config/**/*.env.example (配置模板)
- config/**/*.json (非敏感配置)
- docker-compose.yml (容器编排)
- pyproject.toml, setup.py (Python 项目配置)
- package.json, tsconfig.json (前端配置)

### 3. 文档（仅核心）
- README.md (项目说明)
- CHANGELOG.md (版本历史)
- LICENSE (许可证)

### 4. 构建工具
- Makefile
- Dockerfile, Dockerfile.*
- .dockerignore

## 禁止发布的内容

### 1. 数据文件
❌ data/ (完全排除)
❌ logs/ (完全排除)
❌ reports/ (完全排除)
❌ artifacts/ (完全排除)
❌ .runtime/ (完全排除)

### 2. 内部文档
❌ internal_docs/
❌ docs/archive/ (除 INDEX.md)
❌ docs/design/
❌ docs/plans/
❌ docs/security/
❌ 所有 *_REPORT.md, *_PLAN.md, *_INTERNAL.md

### 3. 敏感配置
❌ .env (真实环境变量)
❌ config/env/*.env (运行时配置)
❌ config/**/*credentials*.json

### 4. 临时文件
❌ *.tmp, *.temp
❌ *.log, *.jsonl
❌ *_screenshot*.png
❌ test_*.temp.py

### 5. AI 助手
❌ .claude/ (除公开配置)
❌ .cursor/, .continue/
❌ .superpowers/

### 6. 个人信息
❌ 所有包含 "pocheang" 的路径
❌ 所有包含本地路径的文档

## 发布前检查清单

```bash
# 1. 检查是否有敏感文件被跟踪
git ls-files | grep -E '^(data|logs|reports|internal_docs|.runtime)/'

# 2. 检查配置文件
git ls-files | grep -E '\.env$' | grep -v '.example'

# 3. 检查日志文件
git ls-files | grep -E '\.(log|jsonl)$'

# 4. 检查内部文档
git ls-files | grep -E '_REPORT\.md|_PLAN\.md|_INTERNAL\.md'

# 5. 统计发布文件数量
git ls-files | wc -l
# 预期：< 500 个文件（主要是代码）

# 6. 检查个人信息
git grep -l 'pocheang' | wc -l
# 预期：0
```
