# Release Notes - v0.6.2.1

**Release Date:** 2026-07-18  
**Type:** Major Infrastructure & Documentation Release  
**Status:** Production Ready  
**Developer:** Po Cheang (po.cheang@gmail.com)

## Executive Summary

QueryMind v0.6.2.1 introduces **enterprise-grade configuration governance**, **standardized deployment infrastructure**, and **comprehensive documentation restructuring** in preparation for public GitHub open source publication. This release includes 16 commits across 284 files, resulting in a net reduction of 23,595 lines through intelligent consolidation and cleanup.

## What's New

### 1. Configuration Governance System

**Single Source of Truth**: All configuration centralized in `config/` directory

**Directory Structure**:
```
config/
├── env/                    # Environment-specific configs
├── profiles/               # Runtime execution profiles  
├── application/            # Application-specific settings
└── observability/          # Monitoring configurations
```

**Unified Deployment**: `./deploy/scripts/deploy.sh [env] [profile]`

### 2. Documentation Restructuring

- **Removed**: 220+ obsolete documents (-36,451 lines)
- **Added**: 64 standardized documents (+12,856 lines)
- **Structure**: Clear 12-category organization
- **Quality**: GitHub-ready markdown with comprehensive cross-linking

### 3. Security & Publication Preparation

- All internal data files removed
- Personal information sanitized
- Strict .gitignore policy (460 lines)
- Publication validation tools added

## Breaking Changes

| Old Location | New Location |
|--------------|--------------|
| `.env` (root) | `config/env/development.env` |
| `docker-compose.yml` | `deploy/compose/compose.yaml` |
| `start.sh` / `start.bat` | `deploy/scripts/deploy.sh` |

## Migration Guide

**Step 1**: Backup your `.env` file
**Step 2**: Copy settings to `config/env/development.env`  
**Step 3**: Use new deployment: `./deploy/scripts/deploy.sh production balanced`

**Local development unchanged**: `conda activate rag-local` + `uvicorn app.api.main:app`
