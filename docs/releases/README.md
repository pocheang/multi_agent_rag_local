## 发布文档规则

- 每个版本只能有一个 canonical release note。
- 当前版本文件名统一使用 `vX.Y.Z-release-notes.md`；旧命名只允许出现在历史归档。
- 发布说明只记录用户可感知的变更、兼容性、迁移和验证结果；实施日志、每日总结和完成报告放入 [历史归档](../archive/INDEX.md)。
- 版本号、发布日期和变更摘要必须与 Git tag、CHANGELOG 和实际代码状态一致。
- 发布前检查 [GitHub 发布流程](../development/github-release.md)。
