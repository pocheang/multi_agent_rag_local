# Project Governance

Lifecycle: intake, shape, authorize, plan, execute, control, accept, close.

Maintain only useful artifacts:

- brief/epic, prioritized backlog, milestones;
- RACI for material decisions;
- RAID log for risks, assumptions, issues, dependencies;
- decision and scope-change log;
- status, acceptance, and operational handoff.

Ready means owner, value, scope, dependencies, risk, acceptance, and test approach are visible. Done means accepted behavior, review, validation, docs, security/data obligations, release path, telemetry, rollback, and follow-up ownership are complete.

Use async daily coordination, weekly governance status, milestone decisions, and periodic roadmap/risk review only when project duration justifies them. Each scope change records reason, impact, approver, baseline, and affected risks.
