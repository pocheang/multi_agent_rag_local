# Decisions

Use a decision-log entry for local reversible choices, ADR for significant repository architecture, RFC for cross-team/public contracts, and exception record for temporary policy deviations.

Record ID, status, date, owner/decision makers, context, drivers, constraints, viable options including no change, decision/rationale, consequences, security/data/operations impact, migration, rollout, rollback, review date, and evidence links.

Statuses: `proposed`, `accepted`, `rejected`, `deprecated`, `superseded`.

Never rewrite history to make an old decision current; add a successor and link both ways. An ADR does not replace implementation planning, threat modeling, review, or approval.
