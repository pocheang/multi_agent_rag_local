# Data Lifecycle

Inventory fields, source, purpose, owner, subject, classification, tenant, residency, and legal/business basis. Map primary stores, vector/graph indexes, chunks/embeddings, caches, logs, backups, analytics, providers, and exports.

Define minimum access, encryption/key ownership, masking, audit, retention, deletion propagation, lineage, quality rules, incident response, and restore.

Migrations use expand, migrate, verify, contract with backup, counts/checksums, representative volume, retry/resume, and rollback. Test tenant isolation, export completeness, deletion, restore, corruption, and idempotency.

Never delete, reindex, restore, export, or migrate real data from implied intent.
