# Documentation and Handoff

Choose the artifact: README for first use; architecture guide for boundaries/flows; ADR/RFC for decisions; API docs for contracts; runbook for alerts/diagnosis/mitigation/rollback/restore; onboarding for environment/access/safe tasks; handoff for ownership/open work/support.

Identify audience, task, owner, confidentiality, and freshness. Verify commands, paths, links, versions, examples, and expected outputs. Put prerequisites and shortest safe path first; link deep reference.

Handoff includes service/scope, accountable owner, architecture/dependencies, environments/access, build/test/deploy/rollback, dashboards/alerts/SLOs, data/security obligations, open RAID/debt/defects, vendors, and sign-off.

Assign owner, last-verified date, and review trigger. Test critical procedures with the receiving owner.
