# Report Templates

Every report has title/type, project/service, period/evidence cutoff, owner/audience/confidentiality, revision/release/environment, status, and executive summary.

| Report | Required body |
|---|---|
| Daily | outcomes, current work, blockers, decisions, changed risks |
| Weekly | milestone progress, scope/schedule/quality/capacity, next plan, RAID, metrics, decisions |
| Milestone | objective/acceptance, delivered/deferred, evidence, variance, defects/debt, go/no-go |
| Test/quality | scope/env/data, commands, counts, coverage/thresholds, defects, security/RAG/performance, residual risk |
| Release | version/commit/digest, changes, validation, migrations/config, security, known issues, rollout/rollback |
| Deployment | target/artifact/window, preflight, stages, observations, deviations, rollback, handoff |
| Incident | severity/impact/duration, timeline, root/contributors, recovery, corrective actions |
| Security | restricted scope, finding/severity/exposure, impact, containment, remediation, disclosure, residual risk |
| Audit | control/period/scope, procedure/sample, evidence mapping, exceptions, remediation/retest |
| Closure | objectives/outcomes, scope, variance, open ownership, docs/runbooks, obligations, lessons, sign-off |

Metrics include value, target/baseline, trend, timestamp, and source. Unknown stays unknown.
